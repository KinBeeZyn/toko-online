# Folder Gambar Produk

Taruh file foto produk kamu di sini, dengan nama PERSIS seperti berikut
(format .jpg, tapi .png/.webp juga boleh asal ganti ekstensi di seed.js):

- kaos-polos.jpg      → Kaos Polos Katun Combed
- sneakers.jpg        → Sepatu Sneakers Casual
- tas-ransel.jpg      → Tas Ransel Laptop
- jam-tangan.jpg      → Jam Tangan Digital
- topi.jpg            → Topi Baseball
- hoodie.jpg          → Jaket Hoodie

Setelah taruh semua file di sini, jalankan ulang:
  cd backend
  npm run seed

Lalu refresh browser (Ctrl+F5) — foto akan otomatis muncul.
